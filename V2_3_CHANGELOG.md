# SPIKE v2.3 changelog

- Added Business Health workspace with factual signals and context coverage.
- Added Research Mode with web research, synthesis, source links, uncertainty rules, and AI-credit accounting.
- Added server `/api/ai/research` endpoint with validation, rate limiting, and credit refunds on failed requests.
- Added clearer distinction between recorded facts, research, experiments, and recommendations.
- Changed the landing-page dashboard preview from `LIVE` to `EXAMPLE` and removed hard-coded business performance numbers.
- Preserved existing Growth, Money, Actions, Customers, Feedback, Creator Console, payments foundation, and AI features.
